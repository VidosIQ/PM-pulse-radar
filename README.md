# Пульс продуктов

Учебный дашборд Product Radar, Show HN и статей Product Radar на Хабре.

Сайт: https://VidosIQ.github.io/PM-pulse-radar/

Запуск запланирован ежедневно в 09:15 по Москве (06:15 UTC) через GitHub Actions; GitHub может задерживать запуск. В публичных репозиториях GitHub может отключить расписание после 60 дней отсутствия активности. Последняя попытка и фактическая свежесть каждого источника видны на странице и в Excel. Кнопка Excel скачивает весь срез, независимо от фильтров.

В Settings → Pages выбери Source: GitHub Actions. Затем Actions → Update dashboard and publish → Run workflow.

Локальный запуск: `python3 scripts/update.py` (Python 3.10+, без сторонних пакетов). Проверки: `python3 -m unittest discover -s tests -v`. Просмотр: `python3 -m http.server --directory docs 8045`.

До 10 карточек первого видимого набора Radar, первые 10 ID Show HN без удалённых/неподходящих записей, до 5 статей RSS. Голоса и score не объединяются. Публикация не равна выходу на рынок; ограниченная выборка не описывает весь рынок. При ошибке источника сохраняются предыдущие данные и дата со статусом cached. История роста и финансовые результаты не придумываются.

Шаблон Excel создан локально с Artifact Tool; облачный сборщик обновляет его стандартными средствами Python/OpenXML. Три листа: Все записи, Данные графиков, О выборке. `templates/index.html` — исходный макет, `docs/` — актуальный сайт и снимок, используемый как кэш при сбоях.
